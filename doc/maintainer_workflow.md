# 維護者工作方式

本頁記錄維護者工作偏好，不取代 [儲存庫契約](../agents.md) 或當次使用者指示；遇到具體授權與環境差異時，以當次指示為準。

- 修改正式副本或同步其他副本前先確認身分、狀態、必要雜湊與目的地既有內容；舊副本預設不更新，只有明確要求時才同步。
- 開發及獨立審查的 Git 工作樹放在主版本的 `worktree/` 下。移動已註冊工作樹前核對路徑與依賴，優先使用 `git worktree move`，再核對提交、分支、狀態與檔案完整性。
- 需要關機、重新開機或登出時遵照當次指示；不要自行觸發。不要自行設定外部遠端或推送到未授權位置。
- 完成候選後依當次授權安排實作者以外的獨立審查與公開部署驗收；新提交重新驗證，不沿用舊提交的通過結果。具體代理分工由本次對話決定，不視為所有貢獻者的通用要求。
- 公開測試報表只列靜態、單元及隔離整合測試；產品的續跑和驗證功能維持。不要將未執行的完整安裝或重開機實機測試宣稱為通過。
